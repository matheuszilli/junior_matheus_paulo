# Projeto de Bloco - TP1

Projeto desenvolvido por Junior, Matheus e Paulo para a análise exploratória do Customer Support Ticket Dataset e a criação de uma API FastAPI com autenticação JWT.

## Estrutura

```text
data/       Dataset utilizado no projeto
eda/        Notebook com a análise exploratória
fastapi/    Código-fonte da API
others/     DFD da API em formato PNG
```

As instruções de instalação e execução serão adicionadas durante o desenvolvimento.
